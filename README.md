# Gadebridge Nursery & Preschool — homepage redesign concept

A homepage redesign concept by AQ Digital for Gadebridge Nursery & Preschool, Hemel Hempstead.
This is **not** the official Gadebridge website.

Plain HTML, CSS and a little vanilla JavaScript: no build step. Open `index.html` locally, or serve it with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Photography and factual content are taken from the nursery's current website, shiningdawn.co.uk.
